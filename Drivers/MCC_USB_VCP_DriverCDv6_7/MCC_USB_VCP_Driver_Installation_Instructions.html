MCC USB to I2C Bus, Virtual Communications Port (VCP) Driver v6.7

MCC USB to I2C Bus Devices Supported:
    iPort DLL/USB (#MIIC-201D/U)
    iPort/USB (#MIIC-204)
    i2cStick (#MIIC-207)

OS: Windows XP[32] / 2003[32] / Vista[32/64] / 7[32/64] / 8[32/64] / 8.1[32/64]

URL: www.mcc-us.com/drivers/MCC_USB_VCP_Driver_v6_7_Update.htm

MCC USB to I2C Bus Adapters provide a Virtual Communications Port (VCP)
interface via this Windows host computer driver. This driver activates a virtual
COM port within the MCC USB to I2C Bus Adapter, and enables application
programs running on the host computer to communicate and control the adapter
via the standard Windows Communications Application Program Interface (API).

the End User License Agreement enclosed.

Driver Installation Instructions:

NOTE: MCC recommends that you leave older versions of driver files on your
system. Other devices on your system may reference older versions of drivers
and may stop functioning correctly if the driver files are removed.

                               (Administrative Privilege Required)

1. Download and save the ZIP file into a folder.
2. Open the folder, Right-Click the ZIP file, and select Extract All (Uncompress).
3. Read and accept the enclosed End User License Agreement.
4. Unplug the MCC USB to I2C Bus Adapter(s) from your PC USB port or USB hub.
5. To add the driver to your system, open the extracted folder and:
5.a. For 64-bit Windows OS: Double-click MCC_USB_VCP_Installer_x64.exe.
5.b. For 32-bit Windows OS: Double-click MCC_USB_VCP_Installer_x86.exe.
6. To load the new driver, plug the MCC USB to I2C Bus Adapter(s) into a USB port
    or self-powered hub.
7. Windows will automatically load the driver and reuse or assign a new COM port
    number (COMn) to the MCC USB to I2C Bus Adapter(s).
8. Use the iPort Message Center or Windows Device Manager to find the assigned
    COMn number.

NOTE: Use of this driver with iPort Utility Pack software (Message Center or Message
Manager) v5.4 or earlier will hide iPort/USB adapters. If you are using an early version
of the iPort Utility Pack, we recommand you upgrade to the latest version at:

                             www.mcc-us.com/iPutilPk/iPutilPk.htm
